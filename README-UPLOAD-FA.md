# Rescue VPN AI — بستهٔ سورس برای GitHub Actions

این بسته فایل‌های کدِ موجود در سند HTML ارسالی را به فایل‌های مستقل پروژه تبدیل می‌کند و Workflow ساخت APK را در مسیر استاندارد GitHub قرار می‌دهد.

## آپلود
1. در GitHub مخزن `vahid250/rescue-vpn` را باز کنید.
2. روی **Add file → Upload files** بزنید.
3. محتویات این پوشه را آپلود کنید؛ خود پوشهٔ `RescueVPN-Android-Source` را به‌صورت یک پوشهٔ تو در تو داخل مخزن قرار ندهید. فایل‌ها باید مستقیماً در ریشهٔ مخزن باشند.
4. Commit changes را بزنید.
5. به تب **Actions** بروید و اجرای **Build Rescue VPN AI APK** را باز کنید.
6. اگر ساخت موفق شد، از پایین صفحهٔ اجرای Workflow بخش **Artifacts** فایل `Rescue-VPN-AI-Debug` را دریافت کنید.

## محدودیت مهم
این بسته از کدهای سند شما استخراج شده است؛ در این محیط کامپایل اندروید اجرا و تأیید نشده است. بنابراین هنوز تضمین نمی‌شود که APK ساخته شود یا اتصال VPN واقعاً کار کند. برای اتصال واقعی، باید یک کانفیگ معتبر WireGuard و سرور WireGuard قابل دسترس داشته باشید. این برنامه خودش سرور رایگان یا کانفیگ آماده ایجاد نمی‌کند.
