# راهنمای ساخت و دریافت APK برنامه R&MA

## ساختار فعلی
- سورس اندروید و فایل‌های Kotlin داخل پوشه `app/` قرار دارند.
- تنها Workflow فعال در مسیر `.github/workflows/build_apk.yml` است.
- فایل‌های Gradle ریشه در کنار پوشه `app/` باقی می‌مانند.

## دریافت APK آزمایشی
1. وارد مخزن GitHub شوید.
2. زبانه **Actions** را باز کنید.
3. اجرای موفق **R&MA Android CI** را انتخاب کنید.
4. در بخش **Artifacts** فایل `RMA-debug-apk` را دریافت کنید.

## نکته‌های مهم
- موفقیت Build فقط یعنی APK ساخته شده است؛ اتصال واقعی VPN باید جداگانه روی گوشی آزمایش شود.
- برای اتصال، کانفیگ معتبر WireGuard و سرور در دسترس لازم است.
- این پروژه سرور رایگان یا کانفیگ آماده تولید نمی‌کند.
- APK نوع Debug برای آزمایش است و نسخه انتشار نهایی امضاشده نیست.

شاخه توسعه فعلی: `rebuild/rma-android-structure`
